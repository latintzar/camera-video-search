# Design decisions

## A question starts with a source interval

Embedding short windows makes search a bounded first stage. The expensive inspection stage receives selected clips and preserves their exact source intervals. CPU query encoding separates routine search from GPU indexing.

## Evidence stays attached to the claim

Visitor chapters, source frames and derived crops carry recording hashes, intervals and model/profile revisions. The interface lets someone move from a tracker to the moment that supports it. A model sentence and an admitted business event have separate records.

## A tracker has one publication

The compact tile and detailed canvas come from the same output revision. Core Trackers use maintained deterministic processors; custom scripts use a declared sandbox/publication boundary. This keeps a summary and its detail attached to the same calculation.

## Readiness is an observed fact

An upload, a prepared source, a verified index and an admitted observation stream are distinct states. Worker heartbeat and source/code identity determine readiness. Publication and Stop reconciliation preserve those boundaries across interruptions.

## Uncertain observations remain reviewable

The original trials retained malformed or unsupported outputs separately from admitted records. This makes quality gaps visible and gives later work a concrete admission/qualification contract. The narrow RetailAction commissioning trial admitted zero observations; the recorded candidate events stayed quarantined.

## Replay and live acquisition have separate proofs

The native player serves recorded sources. Production camera acquisition, arbitrary-camera calibration and live business-event quality need their own commissioning evidence. This derivative labels its supplied fixture layer as **Authored annotations** and its entry as **View footage**.

## Original interface

The release preserves the existing Home, glass tracker tiles, history canvases, player controls, visitor chapters and workspace. Its generic project name is selected through the original vertical manifest. The original product website's generated launch illustration is kept separately from native interface evidence.
