# Authored recording

`synthetic-shop.mp4` and its poster are rendered by `tools/render-fixture.py`. The scene and its three annotations are supplied examples, with one camera-local visitor. `media-provenance.json` records hashes and the authoring recipe. The original admission, projection, tracker and playback code processes these records.

The example labels are a structural workflow fixture. GPU/model and business-event quality have their own acceptance paths.
